# ESP32-2way-comunicator
ESP32 Two-Way Chat Communicator 📡💬A two-way, non-blocking text communicator built on the ESP32 microcontroller. The project uses the nRF24L01+ radio module for wireless transmission, a color TFT display for a split user interface, and a miniature I2C M5Stack CardKB for text input.✨ Main FeaturesTrue 2-way chat: Sending and receiving messages happens without freezing (non-blocking) thanks to an efficient main loop.Shared SPI bus: Both the display and the radio module use a common bus (VSPI), saving valuable GPIO pins on the ESP32.Split UI: The screen is divided into a chat history (top, capacity of 30 messages) and an active typing field with a blinking cursor (bottom).Configured via platformio.ini: The display driver (TFT_eSPI) is fully configured using build_flags. The project is ready to compile out-of-the-box without modifying any library files manually.🛠️ Hardware Requirements2x ESP32-WROOM-32 (30-pin DevKit)2x nRF24L01+ PA+LNA (Radio module)2x 1.8" TFT ST7735S 128x160 (SPI display)2x M5Stack CardKB (I2C keyboard)🔌 Pinout / WiringComponentComponent PinESP32 PinBus / NoteCardKBSDAGPIO 21I2CCardKBSCLGPIO 22I2CSharedSCK / SCLKGPIO 18VSPI ClockSharedMOSIGPIO 23VSPI Data OutnRF24MISOGPIO 19VSPI Data InnRF24CS / CSNGPIO 15SPI Chip Select (Radio)nRF24CEGPIO 4Radio EnableTFTCSGPIO 5SPI Chip Select (Display)TFTDC / A0GPIO 16Data / CommandTFTRST / RESGPIO 17Reset🚀 How to Run the ProjectClone or download this repository and open it in Visual Studio Code with the PlatformIO extension installed.Required libraries (TFT_eSPI, RF24) will be downloaded automatically based on the platformio.ini configuration.Open the src/main.cpp file.For the first device, leave line 13 as: #define UNIT_NUMBER 1 and upload the code to the ESP32.For the second device, change line 13 to: #define UNIT_NUMBER 2 and upload the code to the second ESP32.⚠️ Important Power Supply WarningThe transmission power in the code is currently set to RF24_PA_LOW for safe bench testing. The nRF24L01+ modules (especially the PA+LNA versions with an antenna) are highly sensitive to power fluctuations from the ESP32. If you want to achieve maximum range by switching to RF24_PA_MAX, you must solder a 10uF to 100uF capacitor directly across the 3.3V and GND pins of the nRF24 module. Without it, the ESP32 will likely brownout and reboot during message transmission.📄 LicenseThis project is licensed under the MIT License.
